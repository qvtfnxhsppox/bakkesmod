## Overview

BakkesMod is a free, community-driven plugin framework for Rocket League that unlocks advanced training modes, custom maps, camera adjustments, and real-time game tweaks unavailable in vanilla play.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **BakkesMod** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Free Play Trainer** | Custom ball-spawn modes and shot sequences for focused mechanical training |
| **Workshop Maps** | One-click loading of community-created training and custom game maps |
| **Camera Overrides** | Fine-tune FOV, distance, height, and stiffness beyond official limits |
| **Plugin Manager** | Install, update, and toggle community plugins without touching game files |
